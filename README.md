# 3D Training with Three.js

This repository contains a project focused on learning and implementing 3D graphics using the Three.js library. The project showcases various 3D models and animations to demonstrate the capabilities of Three.js in creating immersive web experiences.

## :dart: About ##

The **3D Training with Three.js** project is designed to help users understand the basics of 3D graphics and how to use the Three.js library to create interactive 3D environments. The project includes various examples that illustrate different features of Three.js, such as lighting, shadows, and animations.

## :sparkles: Features ##

- **3D Models**: Import and render 3D models in various formats.
- **Animations**: Implement animations and transitions for enhanced interactivity.
- **Lighting Effects**: Utilize different lighting techniques to create realistic environments.
- **Interactive Controls**: Enable user interactions with 3D objects.

## :rocket: Technologies ##

The following technologies were used in this project:

- [Three.js](https://threejs.org/)
- [HTML](https://developer.mozilla.org/en-US/docs/Web/HTML)
- [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS)
- [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

## :white_check_mark: Requirements ##

To run this project, you'll need:

- A modern web browser.
- A local server setup (optional, for loading 3D models).

## :checkered_flag: Running the Project ##

1. Clone the repository to your local machine:

    ```bash
    $ git clone https://github.com/Piiii31/3DTraining-with-threejs.git
    ```

2. Navigate to the project directory:

    ```bash
    $ cd 3DTraining-with-threejs
    ```

3. Open the `index.html` file in a web browser to view the project.
